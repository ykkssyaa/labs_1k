# ADR-0004. Ревизии — полные снимки, откат — новая ревизия

- Статус: принято
- Дата: 2026-10-24

## Контекст
Нужна версионность материалов с откатом.

## Решение
Таблица `entry_revisions(entry_id, number, snapshot JSON, author_id, note,
created_at)`. Снимок содержит всё содержимое материала. Откат копирует снимок в
материал и записывает новую ревизию с пометкой «откат к N».

## Отклонённые альтернативы
- **Хранить диффы.** Экономит место, но откат = применение цепочки патчей; ошибка
  в одном звене ломает историю. Материалы маленькие — место не проблема.
- **Откат удаляет ревизии после N.** Теряется история, нельзя «откатить откат».
- **Отдавать версионность Git (файлы материалов в репозитории).** Редакторы не
  работают с Git; Git версионирует код, а не данные пользователей.

## Последствия
+ Любую ревизию можно показать и восстановить за один запрос.
− Таблица растёт линейно с числом сохранений.
