# ADR-0005. Сессии в БД, пароли bcrypt, CSRF-токен сессии

- Статус: принято
- Дата: 2026-10-24

## Контекст
Панель администрирования — серверные HTML-формы. Нужны вход, выход, роли.

## Решение
Таблица `sessions(token_hash, user_id, csrf, expires_at)`. В cookie — случайный
токен (32 байта), в БД — его SHA-256. Cookie `HttpOnly`, `SameSite=Lax`.
Каждая POST-форма несёт CSRF-токен сессии. Пароли — bcrypt.

## Отклонённые альтернативы
- **JWT в cookie.** Нельзя отозвать сессию при блокировке пользователя без
  чёрного списка — то есть всё равно таблица.
- **Basic Auth.** Нет выхода, нет нормальной формы входа.
- **Хранить токен в БД как есть.** Утечка БД = захват сессий.

## Последствия
+ Выход и блокировка пользователя сразу закрывают все его сессии.
− Запрос в БД на каждый запрос к админке (для SQLite незаметно).
