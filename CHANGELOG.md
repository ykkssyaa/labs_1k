# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — SemVer.

## [1.0.0] — 2026-10-24

### Этап 5 — аналитика и релиз
- Сбор просмотров материалов: обезличенный посетитель (HMAC с дневной солью), фильтр ботов и предзагрузки, окно повторов 30 минут.
- Дневные свёртки `metrics_daily`, `metrics_site_daily` (идемпотентные), команда `vestnik rollup` и фоновая свёртка раз в час.
- Экран статистики: просмотры по дням, топ-10, публикации по дням и типам, активность сотрудников, медиана модерации, выгрузка CSV.
- Команда `vestnik seed` с демо-данными; `CHANGELOG.md`, `docs/DEPLOY.md`.

### Этап 4 — шаблонный слой и публичная часть
- Слой `render`: темы с наследованием (`extends`), partial-шаблоны, блоки; собственный markdown с экранированием.
- Темы `classic` и `newspaper`; шаблон материала по типу (`entry-<тип>`) или общий по схеме.
- Публичные страницы, меню из рубрик и страниц, поиск, `sitemap.xml`, `robots.txt`, OpenGraph.
- REST API v1 с пагинацией и фильтрами по таксономии.
- Переключение темы администратором.

### Этап 3 — панель администрирования
- Роли и права из `config/roles.json` (администратор, редактор, автор).
- Вход, сессии в БД, CSRF; управление пользователями.
- CRUD материалов с формой из схемы, модерация, пакетные операции, фильтры и поиск, ревизии и откат, рубрики, медиатека, журнал действий.

### Этап 2 — ядро
- Реестр типов из JSON-схем, валидация полей, миграции схем.
- Материалы, ревизии (полные снимки, откат новой ревизией), жизненный цикл.
- Таксономия (рубрики с иерархией, теги), медиа с производными размерами.

### Этап 1 — каркас
- Спецификации, ADR 0001–0006, харнесс агента.
- Go + SQLite, миграции БД при старте, `make check`, Docker.
