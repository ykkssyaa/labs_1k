---
Посмотри `git diff main...HEAD` и проверь по правилам из CLAUDE.md:
- нет ли имён типов материалов в ядре;
- все ли проверки прав идут через access.Policy;
- нет ли `template.HTML` из пользовательских данных;
- не изменены ли применённые миграции;
- есть ли тесты на каждый критерий спецификации.
Выведи список нарушений с файлом и строкой. Ничего не исправляй.
