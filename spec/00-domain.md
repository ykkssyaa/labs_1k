# 00. Предметная область

## Издание

«Вестник» — городское онлайн-издание. Редакция публикует статьи, новости,
рецензии и афишу событий; есть статические страницы («О редакции», «Контакты»).
Материалы проходят модерацию: автор пишет черновик, редактор проверяет и
публикует, устаревшие материалы уходят в архив.

## Пользователи

| Роль | Кто это | Что делает |
|---|---|---|
| Администратор | технический владелец | всё, включая пользователей, темы, статистику |
| Редактор | выпускающий редактор | модерирует, публикует, архивирует любые материалы, ведёт рубрики |
| Автор | корреспондент | пишет свои материалы и отправляет их на модерацию |
| Читатель | анонимный посетитель | читает публичную часть и API |

## Что должна уметь система (сквозной список)

1. Хранить материалы нескольких типов; тип описывается схемой, а не кодом.
2. Вести жизненный цикл публикации и ревизии каждого материала с откатом.
3. Классифицировать материалы рубриками (иерархия) и тегами.
4. Хранить медиафайлы и строить производные размеры изображений.
5. Давать редакции панель администрирования с ролями и журналом действий.
6. Показывать читателям сайт в одной из тем и отдавать материалы через REST API.
7. Считать просмотры и активность редакции и показывать статистику.

## Стек

- Go 1.25, стандартный `net/http` (роутинг с шаблонами путей Go 1.22+).
- SQLite через `modernc.org/sqlite` (чистый Go, без cgo), собственный механизм миграций.
- Шаблоны — изолированный слой `internal/render` поверх `html/template`.
- Тесты — `go test`, линтер — `gofmt` + `go vet` + `staticcheck`.
- Запуск — `make run` или `docker compose up --build`.

Почему так — см. `docs/adr/`.
